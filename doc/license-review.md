# Fisica Scale SDK License 2.0 검토 자료

`LICENSE`는 2026-10-17 정책(기본·전체 모드, SDK 키 = 좌석)에 맞춘 Version 2.0 **검토용 초안 2**다.
한국어 원문과 영어 번역이 한 파일에 있고 한국어 원문이 우선한다. 법무 검토를 마치지 않았다. 2026-10-14의 2.0 첫 문안과
2026-10-17 문안을 같은 버전 번호로 다시 썼다([정책 이력](policy-history.md)).
이전 본문은 [LICENSE-1.0.txt](LICENSE-1.0.txt)와 git 이력에 보존한다. 2.0은 기존 계약, 1.0으로 이미 제공한 배포본,
과거 MIT 등으로 제공한 버전의 권리를 자동으로 바꾸지 않는다.

엔지니어링이 제품 정책과 사용자 결정(2026-10-17)을 문장으로 옮긴 것이다. 아래 "결정한 조항"도 표현과 국내법상 효력은
변호사 확인이 필요하다. 법무 검토를 마치면 초안 표기를 떼고 2.0으로 확정한다(포털 `terms_version`도 함께 바꾼다).

## 검토가 필요한 항목

- 같은 버전 번호(2.0)로 문안을 바꾼 것: 이전 문안(`2.0-draft`) 동의 기록의 효력과 새 문안 동의를 받는 방법.
  포털은 다음 신청(체험·연장·계약) 때 현재 문안(`2.0-draft.2`) 동의를 받는다(사용자 결정).
- 13조 책임 한도: 무료 사용자에게 0원 상한이 약관규제법상 유효한지, 개인(소비자) 파트너에 대한 효력, 영어 번역의 표현.
- 14조 전속 관할: 개인(소비자)에 대한 효력과 해외 사용자에 대한 효력.
- 4조 위반 시 조치: 시정 기간을 숫자로 둘지(지금은 "시정 요청 뒤에도 계속되면"), 이용권 종료 시 이미 받은 대금 처리.
- 12조 의료 고지: 장비 자체의 분류(의료기기 여부)와 표현이 맞는지.
- 8조 역설계 금지의 국내법상 범위(저작권법의 프로그램코드역분석 허용 규정 등)와 해외 사용자에 대한 효력.
- 9조: 활성화 때 보내는 앱 ID·PC 해시와 서버가 저장하는 활성화·갱신·해제 시각이 개인정보에 해당하는지,
  고지 문구와 보유 기간. 개발자 포털의 개인정보 처리방침 초안과 맞춘다.
- 3조가 승인·계약서와 "개발자 포털에 게시된 조건"을 참조하는 방식(숫자를 약관에 적지 않음)의 유효성과,
  게시 조건이 바뀔 때 이미 승인된 체험·계약에 적용되는 범위.
- 4조: 키 재판매·양도 금지와 한 앱 ID 한 계약 원칙, 위반 시 키 폐기의 표현.
- 10조 "사용 추적 없음"과 서버의 활성화·갱신 기록 보관 방식이 서로 맞는지(갱신 기록을 사용 이력으로 쓰지 않음).
- 개발자 포털의 개인정보 처리방침 초안(`/docs/privacy`)에 적은 보유 기간 중 상업 신청자 연락처(체험 1년, 계약 5년)는
  사용자가 정한 값이고, 계정·신청 내용·SDK 키·체험 사용 기록(5년)·운영 기록(1년)은 **엔지니어링 제안값**이다.
  보유 기간이 지난 정보의 자동 파기는 아직 포털에 구현돼 있지 않다. 처리 위탁(호스팅 등)은 아직 정하지 않았다.
- 개인정보 보유 기간(엔지니어링 제안값)과 개인정보 보호책임자(대표이사)는 2026-10-17에 확정했다.
- 공인 판매처 목록: 개발자 포털 `/docs/sellers`에 게시한다. Care&Co 외 판매처는 아직 받지 못했다.
- 보증 부인 조항의 국내법상 유효 범위.
