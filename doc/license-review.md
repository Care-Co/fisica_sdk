# Fisica Scale SDK License 2.0 검토 자료

`LICENSE`는 2026-10-17 정책(기본·전체 모드, SDK 키 = 좌석)에 맞춘 Version 2.0 **검토용 초안**이다.
법무 검토를 마치지 않았다. 2026-10-14의 2.0 첫 문안을 같은 버전 번호로 다시 썼다([정책 이력](policy-history.md)).
이전 본문은 [LICENSE-1.0.txt](LICENSE-1.0.txt)와 git 이력에 보존한다. 2.0은 기존 계약, 1.0으로 이미 제공한 배포본,
과거 MIT 등으로 제공한 버전의 권리를 자동으로 바꾸지 않는다.

엔지니어링이 제품 정책을 문장으로 옮긴 것이다. 표현, 준거법, 책임 범위, 소비자·개인정보 법규는 변호사 확인이 필요하다.

| Version 1.0 | Version 2.0 초안(2026-10-17) |
|---|---|
| 2조: 무료 사용은 비상업적 용도만 | 2조: 기본 사용권 = 기본 모드. 상업 사용 포함, 등록·키 불필요, 기간 제한 없음 |
| 3조: 모든 상업적 사용에 서면 상업 계약과 사용료 | 3조: 전체 모드만 체험(1회, 승인)·연장(비상업, 재량)·계약(상업)이 필요. 6조: OEM·리브랜딩·재판매·정품 외 사용은 별도 계약 |

새 약관과 무관하게 MIT 조건으로 계속 쓸 수 있다. 2.x 이후 추가된 것(네이티브 코어, 세션 엔진, 다중 언어 래퍼,
SDK 키와 모드)에만 새 약관이 적용된다.

## 검토가 필요한 항목

- 같은 버전 번호(2.0 초안)로 문안을 바꾼 것: 2026-10-17 전 동의 기록의 효력과 새 문안 동의를 받는 방법.
  포털은 다음 신청(체험·연장·계약) 때 현재 문안 동의를 받는다.
- 8조 역설계 금지의 국내법상 범위(저작권법의 프로그램코드역분석 허용 규정 등)와 해외 사용자에 대한 효력.
- 9조: 활성화 때 보내는 앱 ID·PC 해시와 서버가 저장하는 활성화·갱신·해제 시각이 개인정보에 해당하는지,
  고지 문구와 보유 기간. 개발자 포털의 개인정보 처리방침 초안과 맞춘다.
- 3조가 승인·계약서와 "개발자 포털에 게시된 조건"을 참조하는 방식(숫자를 약관에 적지 않음)의 유효성과,
  게시 조건이 바뀔 때 이미 승인된 체험·계약에 적용되는 범위.
- 4조: 키 재판매·양도 금지와 한 앱 ID 한 계약 원칙, 위반 시 키 폐기의 표현.
- 10조 "사용 추적 없음"과 서버의 활성화·갱신 기록 보관 방식이 서로 맞는지(갱신 기록을 사용 이력으로 쓰지 않음).
- 개발자 포털의 개인정보 처리방침 초안(`/docs/privacy`)에 적은 보유 기간 중 상업 신청자 연락처(체험 1년, 계약 5년)는
  사용자가 정한 값이고, 계정·신청 내용·SDK 키·체험 사용 기록(5년)·운영 기록(1년)은 **엔지니어링 제안값**이다.
  보유 기간이 지난 정보의 자동 파기는 아직 포털에 구현돼 있지 않다. 처리 위탁(호스팅 등)과 개인정보 보호책임자도 정해야 한다.
- "정품"과 공인 판매 경로의 정의.
- 책임 제한과 보증 부인 조항의 국내법상 유효 범위.
