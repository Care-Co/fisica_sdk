# Fisica Scale SDK License 2.0 검토 자료

`LICENSE`는 2026-10-14 정책에 맞춘 Version 2.0 **검토용 초안**이다. 법무 검토를 마치지 않았다.
2026-10-13 초안에 있던 9조 사용 기록 수집·보고는 2026-10-14에 제외했다([정책 이력](policy-history.md)).
이전 본문은 [LICENSE-1.0.txt](LICENSE-1.0.txt)에 보존한다. 2.0은 기존 계약, 1.0으로 이미 제공한 배포본,
과거 MIT 등으로 제공한 버전의 권리를 자동으로 바꾸지 않는다.

엔지니어링이 제품 정책을 문장으로 옮긴 것이다. 표현, 준거법, 책임 범위, 소비자·개인정보 법규는 변호사 확인이 필요하다.

## 1.0과 달라진 점

| Version 1.0 | Version 2.0 초안 |
|---|---|
| 2조: 무료 사용은 비상업적 용도만 | 2조: 기본 SDK 사용권이 일반 상업적 사용까지 포함 |
| 3조: 모든 상업적 사용에 서면 상업 계약과 사용료 | 3조: 등록과 약관 수락. 4조: OEM·리브랜딩·재판매·정품 외 사용 등 예외만 별도 계약 |
| 4조: 배포 시 Care&Co 배포 식별자 유지 | 6조: 바이너리에 회사별 식별자가 없음. 라이선스와 고지만 유지 |
| 6조: 온라인 활성화·사용 기록 없음 | 8조: 차단하지 않는 온라인 갱신과 오프라인 검증(30일은 확인 정보 갱신 기준). 9조: SDK 사용 추적 없음 |
| 계약 종료 후 의무는 계약에 위임 | 5조: 계약 종료가 기본 사용권·장비 소유권·장비 등록을 없애지 않음 |

## 적용 라이선스 구분

| 대상 | 라이선스 |
|---|---|
| 공개 래퍼, 예제, 문서, 공개 C 헤더 | Fisica Scale SDK License (소스 공개, 수정·앱 포함 배포 허용) |
| 네이티브 코어 | Fisica Scale SDK License. 컴파일된 바이너리만 제공, 소스 비공개 |
| 코어에 포함된 Monocypher 4.0.2 | CC0-1.0 또는 BSD-2-Clause (CC0 선택) |
| Python GUI extra의 PyQt5 | GPL 또는 상용 라이선스 (별도 조건) |
| NumPy, bleak, pyserial, System.IO.Ports 등 의존성 | 각자의 오픈소스 라이선스 |
| 포함된 모델 | 없음 |
| PyPI `fisica` 1.0.0, 1.0.1 | MIT. 이미 부여된 권리이며 2.0으로 소급 제한하지 않는다 |

소급 제한을 하지 않으므로 생기는 영향: 1.0.x는 순수 Python 구현 전체가 MIT로 공개돼 있어, 그 버전은
새 약관의 등록·별도 계약 조건과 무관하게 MIT 조건으로 계속 쓸 수 있다. 2.x에서 추가된 것(네이티브 코어,
세션 엔진, 다중 언어 래퍼, 확인 정보)에만 새 약관이 적용된다.

## 검토가 필요한 항목

- 1.0 또는 서명 계약으로 이미 사용 중인 회사에 대한 전환 방법.
- 온라인 갱신(8조) 때 서버에 전달되는 정보(확인 정보 토큰과 통신에 따르는 접속 정보)에 대한 고지 문구.
- 9조의 "사용 추적 없음"과 서버의 갱신 요청 기록 보관 방식이 서로 맞는지(갱신 기록을 사용 이력으로 쓰지 않음).
- "정품"과 공인 판매 경로의 정의.
- 책임 제한과 보증 부인 조항의 국내법상 유효 범위.
