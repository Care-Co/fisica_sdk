## 2026-10-17: LICENSE 2.0 확정

사용자 결정(2026-10-17)으로 검토용 초안 2의 조항을 그대로 두고 초안 표기를 뗐다. 머리말에서 "검토를 위해 공개, 법무 검토 전"
문장을 지웠고, 포털 `terms_version`을 `2.0-draft.2`에서 `2.0`으로 바꿨다. 포털은 다음 신청 때 `2.0` 동의를 받는다.
`2.0-draft.2` 동의 기록은 조항이 같은 문안에 대한 것이다. 이 저장소에는 변호사 검토 기록이 없으며, 변호사 확인을 권하는
항목은 [license-review.md](license-review.md)에 남겼다.

## 2026-10-17: LICENSE 2.0 검토용 초안 2

사용자가 약관 조항을 정했다(2026-10-17). 버전 번호는 2.0을 유지하고, 법무 검토를 마치면 초안 표기를 떼고 확정한다.
같은 번호의 이전 문안과 구분하려고 개발자 포털의 `terms_version`을 `2.0-draft`에서 `2.0-draft.2`로 바꿨다.
포털은 다음 신청(체험·연장·계약) 때 현재 문안 동의를 받으며, 이미 받은 동의를 다시 받지는 않는다.
그래서 `2.0-draft` 동의 기록은 동의 시각에 따라 2026-10-14 문안 또는 2026-10-17 첫 문안에 대한 것이다.
2026-10-17 첫 문안은 git 이력(커밋 `d3a4776`의 `LICENSE`)에 있다.

바뀐 내용(조항별 표는 [license-review.md](license-review.md)):

- 한국어 원문과 영어 번역을 한 파일에 둔다. 뜻이 다르면 한국어 원문이 우선한다(14조).
- 준거법은 대한민국 법, 관할은 Care&Co 본점 소재지 법원 전속(14조).
- 총 책임은 직전 12개월 동안 SDK와 관련해 받은 금액까지. 고의·중과실, 생명·신체 손해는 예외(13조).
- 위반이 시정 요청 뒤에도 계속되면 그 이용권을 종료한다. 기본 사용권은 유지(4조).
- SDK는 의료기기가 아니다(12조, 새 조항). 그 뒤 조 번호가 하나씩 밀렸다(보증과 책임 13조, 연락처 15조).
- "장비"의 정의에 공인 판매처와 그 목록 게시를 넣었다(1조). 키 해제에 온라인 해제를 넣었다(4·9조).

## 2026-10-17: LICENSE 2.0 초안을 같은 번호로 다시 씀

2.0은 아직 법무 검토 전 초안이라 버전 번호를 올리지 않고 문안을 바꿨다(2026-10-17 사용자 결정).
개발자 포털의 약관 버전 표기(`terms_version`)도 `2.0-draft` 그대로다. 그래서 2026-10-17 전에 포털에서
`2.0-draft`에 동의한 기록은 2026-10-14 문안에 대한 동의였다. 이 날짜 전의 동의 기록과 이후의 동의 기록은
동의 시각으로 구분한다. 2026-10-14 문안은 git 이력(커밋 `65615a5`의 `LICENSE`)에 있다.

바뀐 내용의 요약은 [license-review.md](license-review.md)에 있다. 핵심:

- 기본 사용권(2조)은 **기본 모드**로 정의했다. 상업 사용 포함, 등록·키 불필요, 기간 제한 없음.
- 전체 모드(3조)는 체험·연장·계약 중 하나의 키가 그 앱·PC에 활성화된 동안만 쓴다. 구체적인 기간·좌석·
  이동 상한·유예는 승인·계약서와 개발자 포털에 게시한 조건을 따른다(약관에 숫자를 적지 않음).
- 키와 좌석(4조), 신청(5조), 역설계와 모드 판정 우회 금지(8조), 활성화 때 보내고 저장하는 정보(9조)를 새로 적었다.
- "어떤 상태도 기능을 차단하지 않는다"(이전 8조)는 삭제했다. "사용 추적 없음"(10조)은 유지하고, 활성화·갱신·해제
  기록이 사용 기록이 아님을 적었다.

## 2026-10-13의 사용 기록 정책 (대체됨)

회사+계약별로 사용 여부, 마지막 실제 사용일시(기기 시계), 계약 만료·폐기 상태에서의 사용 관측 여부를
로컬에 기록하고, 온라인일 때 `/sdk/v1/usage`로 보고하는 내용이었다. 측정 횟수·개인 정보·하드웨어 식별자는
수집하지 않고, 임시 `report_id`로 재시도를 중복 제거하며, 서버 확인 후 로컬 기록을 지우는 규칙을 두었다.

2026-10-14에 이 기능 전체를 제외했다. 전체 문장은 git 이력(커밋 `427d400`의 `doc/entitlement.md`,
`doc/entitlement-api.yaml`, `LICENSE` 9조)에 있다. 이 정책으로 작성했던 코드도 2026-10-14에 제거했다.

## 2026-10-14의 비차단 확인 정보 정책 (대체됨)

기본 사용권은 항상 `granted`, 확인 정보의 최신성(최대 30일)과 계약 상태는 따로 표시하되 어떤 상태도
기능을 막지 않는 방식이었다(C ABI 1.4, SDK 2.4.0). 확인 정보는 회사·계약을 알려 줄 뿐 앱·기기에 묶이지 않았다.
2026-10-17의 C ABI 2.0(SDK 3.0.0)에서 기본·전체 모드와 좌석 키로 바꿨다. 이전 형식 토큰은 지금도 서명을
검증해 회사·계약을 보여 주지만 기본 모드로만 동작한다(`legacy_token`). 배포한 패키지가 없어 이전 ABI 호환은 두지 않았다.
